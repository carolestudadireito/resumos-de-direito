# Resumos de Direito

Loja estática de materiais em PDF para o concurso de **Escrevente TJSP**: 12 matérias em lettering e duas coletâneas (clássica e lettering), com 14 checkouts individuais na Eduzz.

## Prévia e publicação

Abra `index.html` no navegador ou sirva a pasta com um servidor estático. O site pode ser publicado no GitHub Pages, sem compilação e sem dependências para o visitante.

Na prévia local, a faixa de diagnóstico mostra informações de configuração que não aparecem no site publicado.

## Onde editar

| Arquivo | Conteúdo |
| --- | --- |
| `config/loja.js` | Dados gerais, contatos, capas do topo e perguntas frequentes |
| `config/escrevente.js` | Matérias, imagens e checkouts de Escrevente TJSP |
| `css/estilo.css` | Componentes e estilos básicos |
| `css/editorial.css` | Identidade editorial e ajustes para celular |
| `assets/escrevente/` | Artes das matérias de Escrevente em WebP |

Os preços são exibidos na Eduzz.

Ao alterar links, use a página `verificar.html` para conferir os checkouts. Só são aceitos links HTTPS de domínio Eduzz.

A conferência dos destinos não envia dados nem realiza compras na Eduzz.
